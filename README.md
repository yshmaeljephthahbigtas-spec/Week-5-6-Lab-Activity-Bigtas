# Week 5-6 Lab Activity Bigtas
A Windows Forms App demonstrating GACHA and Big-O Notation.

## Features

- Data example
- Algorithm example
- One-Dimensional Array
- O(1) Constant Time
- O(n) Linear Time
- O(log n) Logarithmic Time
- O(n²) Quadratic Time
- O(2ⁿ) Exponential Time
- League Champion Gacha
- Gacha Inventory

## Made With

- C#
- Windows Forms
- Visual Studio
